# Changelog

## 0.1.0

First release.

- Time each person spends in each zone, per day, stored with no expiry
- Import of the days still in the Home Assistant history when set up, and the `zone_time.rebuild` action
- Sensors per person: today, this week, this month and this year, with one attribute per zone
- Zone Time card, loaded automatically: person and period selectors, navigation to any past period, donut, bars, day timeline and stacked bars per day or month
- Integration icon and logo
- English and Portuguese
